# Changelog

## 1.2.0

- Removed the shipped best-of-N workflow surface: the 16 named
  `*-alpha/beta/gamma/delta` specialist variants, the `wildcard` utility agent,
  and the `best-of-n-with-judge` reserved-skill grant.
- Kept the generic custom-agent mechanism, suffix-based policy inheritance, the
  three fast-lane utilities (`scout`, `validator`, `gist`), and the
  `orchestrator-beta` / `orchestrator-delta` fallback profiles.
- Updated documentation and host smoke coverage for the smaller 15-role preset.
